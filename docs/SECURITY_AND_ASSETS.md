# 公開リポジトリの機密情報・外部素材について

この文書は、UnityプロジェクトをGitHubで公開する際の注意事項をまとめたものです。**ゲームをプレイできることと、含まれるすべての素材を第三者へ再配布できることは別**です。

## 1. unityroomランキングのローカル設定

ランキング送信時に使用するHMACキーは、GitHubに公開しないようにしています。現在の実装は、シーンやC#ソースにキーを直接書く代わりに、**Git管理外のローカルファイル**から読み込みます。

1. unityroom側で、以前GitHubに記録されていたキーを無効化し、**新しいキー**を発行してください。
2. ローカルのUnityプロジェクトに `Assets/Resources/` フォルダを作成します。
3. その中に `unityroom-ranking-hmac.txt` を作成し、**新しいHMACキーだけを1行で記入**します。
4. ファイルは `.gitignore` に登録済みです。Gitへの追加対象になっていないことを確認してください。
5. Unityエディターから動作を確認し、ランキング送信を利用する場合は新しいキーを組み込んでゲームを再ビルドしてください。

```text
Assets/
  Resources/
    unityroom-ranking-hmac.txt    ← ローカル専用。Gitへコミットしない
```

`UnityroomRankingSubmitter.cs` は `Resources.Load<TextAsset>("unityroom-ranking-hmac")` で読み込みます。キーが見つからない場合、ランキング送信は実行せず、警告ログを出します。その他のゲーム処理はランキングキーを必要としません。

**注意：** この方式は「GitHubのソースコードにキーを含めない」ための対策です。WebGLに組み込んだクライアント側のキーを完全な秘密として保護するものではありません。署名鍵の厳密な機密性が必要な場合は、サービスの推奨する認証方式やサーバー側での署名管理を検討してください。

### 過去のコミットについて

公開シーン `Assets/Scenes/SampleScene.unity` にHMACキーが含まれていたため、現行ファイルから削除しました。ただし、**過去のGit履歴は変更していません**。キーを削除したコミットだけでは旧キーの漏えい対策にならないため、上記のキー再発行と旧キー無効化が必要です。

## 2. 外部アセットの確認

以下は、リポジトリ内の実ファイル名やREADMEから確認できた項目です。**ライセンスを確認したという記録がない素材は、再配布許可を確認できていません。**

| 対象 | 現状 | 公開時の注意 |
| --- | --- | --- |
| Unityの2Dキャラクターサンプル | README上でNinja_Catの利用を明記。サンプルフォルダは `.gitignore` の対象 | 使用したアセットの正確な配布元・ライセンスを確認。Asset Store素材のソース形式での再配布には制約があります |
| `Assets/font/Futehodo-MaruGothic_1.03/` | フォントファイルがリポジトリ内に存在 | 作者の配布ページにライセンス説明がありますが、**収録したバージョン1.03**に適用される条件・必要なライセンス文書を確認してください |
| `Assets/images/` と `Assets/sounds/` | 画像・効果音のファイルが公開中 | 各素材について作者・取得元・利用規約を確認し、必要なら帰属表示を追加してください |
| Pngtree名を含む画像 | 未使用と判断できた画像を現行ブランチから削除 | 過去履歴には残る可能性があります。再配布許諾がない場合は履歴からの除去も別途検討してください |

## 3. 公開前のチェック

- APIキー、HMACキー、アクセストークン、パスワードをGitへコミットしない
- `.gitignore` に登録していても、**過去にコミットしたファイルはGitの履歴に残る**ことを理解する
- 第三者素材は「ゲームへの組み込み」と「生ファイルの再配布」の条件をそれぞれ確認する
- 権利条件が不明な素材は、権利確認が取れるまでは公開を控え、必要なら自作素材・再配布可能素材へ差し替える

本ドキュメントは利用条件の確認状況を整理したものです。各素材の使用・公開が許諾されていることを保証するものではありません。
